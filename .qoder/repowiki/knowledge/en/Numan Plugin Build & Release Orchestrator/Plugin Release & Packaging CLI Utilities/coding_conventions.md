- Every script follows the same CLI pattern: define an `argparse.ArgumentParser`, parse arguments in `main()`, wrap the body in a try/except that prints `FAIL: <message>` to stderr and returns 1, and invoke via `raise SystemExit(main())`.
- External subprocess calls use `subprocess.run(..., check=False, capture_output=True, text=True, timeout=COMMAND_TIMEOUT_SECONDS)` with a module-level `COMMAND_TIMEOUT_SECONDS = 30` constant, and errors are surfaced by raising `RuntimeError` or `ValueError` rather than letting exceptions propagate.
- Failure paths consistently write diagnostic output to `sys.stderr` using the `FAIL:` prefix while success messages go to stdout or stderr with an `OK:` prefix, keeping machine-parseable output separate from human-readable diagnostics.
- GitHub API interactions are performed exclusively through the `gh` CLI with explicit `--method`, `--raw-field`, and `-F` flags rather than higher-level SDKs, and URLs are constructed with `urllib.parse.quote(tag, safe='')` for safe path encoding.
