Flat collection of independent Python scripts, each a self-contained CLI with a `main()` entry point invoked via `if __name__ == "__main__"` returning an exit code. Two core libraries provide shared validation logic: `validate_manifest.py` defines the schema for `manifest.json` (required fields, default/excluded targets, upstream tag resolution) and is imported by `gen_spec.py`; `release_transaction.py` encapsulates the claim/finalize/cleanup lifecycle for draft releases. The pipeline flows left-to-right across scripts: `package_plugin.py` produces deterministic `.tar.gz`/`.zip` archives and emits `PACKAGED\t...` TSV lines; `gen_spec.py` consumes those lines plus `manifest.json` to produce a registry spec JSON consumed by numan-registry's `add-package.py`; `release_transaction.py` claims a tag + draft release, verifies assets match local checksums, then publishes or cleans up on failure; `ensure_release_absent.py` gates the workflow by asserting no prior tag/release exists. All external I/O goes through the `gh` CLI via `subprocess.run`, with a uniform 30-second timeout constant and error handling that prints `FAIL:` messages to stderr and returns 1 on failure.
