Each script is run directly with `python scripts/<script>.py --args ...`. `release_transaction.py` requires the `GITHUB_OUTPUT` environment variable set by GitHub Actions when running `claim`. All scripts require the `gh` CLI to be authenticated against the target repository. `gen_spec.py` expects a `manifest.json` at the repository root and a TSV file containing `PACKAGED\t<target>\t<filename>\t<sha256>\t<exe>` lines produced by `package_plugin.py`.
