Builds are triggered manually via the **build-plugins** workflow with an `only=` package list; PRs/pushes cannot publish. After a successful run, generated `spec-*.json` files are dropped into `numan-registry/specs/` and ingested via `python scripts/add-package.py --spec … --write` there. Lifecycle validation runs against a clean `NUMAN_ROOT` exercising search/info/install/activate/doctor/list/remove/gc on each target OS.
